d3-wordcloud for D3 v7+

A modern word cloud layout — with incremental placement, so clouds can be built and animated one word at a time.

ESM + UMD D3 v7 MIT 0 peer deps beyond d3-dispatch

Install

Via npm (once published) — or import the source directly in the browser using an import map.

npm install d3-wordcloud

Basic word cloud

Supply a words array where each object has a text string and a numeric value. The default font size accessor is d => Math.sqrt(d.value).

Incremental placement

API reference

All configuration methods are chainable and follow the getter/setter pattern: called with no argument they return the current value; called with an argument they set it and return cloud. Accessors accept either a constant value or a function (datum, index) → value.

MethodDefaultDescription
cloud.start()Clear the board and place all .words() from scratch. Returns cloud.
cloud.stop()Cancel any running async layout and free sprite memory.
cloud.add(words)Place words into the existing layout without re-placing already-placed words. Initialises automatically if start() has not been called.
cloud.clear()Reset persistent state (board, bounds, placed list). The next start() begins from an empty board.
cloud.placed()Return a snapshot array of all successfully placed word datums (cumulative across start() and add() calls).
cloud.words(array)[]Input word data.
cloud.size([w, h])[256, 256]Layout area in pixels. Word x/y coordinates are relative to the centre.
cloud.text(fn)d => d.textText string accessor.
cloud.fontSize(fn)d => Math.sqrt(d.value)Font size in pixels.
cloud.font(fn)"serif"Font family.
cloud.fontStyle(fn)"normal"CSS font-style.
cloud.fontWeight(fn)"normal"CSS font-weight.
cloud.rotate(fn)random ±30°/60°Rotation in degrees.
cloud.padding(fn)1Extra spacing around each word (pixels).
cloud.spiral(name | fn)"archimedean""archimedean" or "rectangular". Pass a custom (size) => t => [dx, dy] factory for full control.
cloud.random(fn)Math.randomRNG. Pass a seeded function for reproducible layouts.
cloud.timeInterval(ms)InfinityMax milliseconds per event-loop tick. Lower values keep the UI responsive during large layouts.
cloud.canvas(fn)() => document.createElement("canvas")Canvas factory. Override for server-side rendering (e.g. node-canvas).
cloud.on("word", fn)Called once per successfully placed word. Argument: the word datum.
cloud.on("end", fn)Called when the current batch finishes. Arguments: (batchPlaced, bounds).
